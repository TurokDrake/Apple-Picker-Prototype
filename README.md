## Apple Picker Prototype

> 本游戏实例出自《游戏设计、原型与开发 基于Unity与C#从构思到实现》。本仓库使用Unity2022版本完成该教程。  

游戏简介：苹果树每隔一段时间掉落苹果，玩家需要依靠手头仅有的三个篮子接住苹果。如果苹果掉落至地上而摔烂，玩家需要受到惩罚——损坏一个篮子。尽可能地接住所有苹果！
